# Azariush Hussain — Portfolio

Personal portfolio with a responsive layout, animated backend architecture diagram, project links, certifications, and a downloadable resume.

Live site: https://azariushhussain.github.io/

## Run locally

Run `python -m http.server 4173` and open http://localhost:4173.

## Publish updates

GitHub Pages serves the root of the `main` branch. Push changes to `main` to publish updates.

## Freelance portfolio

The separate client-facing portfolio is at https://azariushhussain.github.io/freelance/. Its source is in `freelance/`, including Aurnelia case-study screenshots, service offerings, project enquiry email drafting, and direct email/phone contact links. The enquiry form opens an email draft; it does not submit to a backend.
